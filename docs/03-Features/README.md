# Features

One feature: Marker, the working-session board agent.

The spec is written here after [ADR-0001](../05-Decisions/ADR-0001-decider-policy-on-the-board.md) is accepted. It covers:

- who the board is for (a person running a working session)
- the conversation: messy speech in, marks on the board out
- the autonomy split in [Architecture](../01-Architecture/README.md) (Decider classifies and grounds; Bedrock writes)
- what the demo must show in under three minutes
- what prototype scope leaves out (accounts, multi-user, cross-session memory, production hardening)
